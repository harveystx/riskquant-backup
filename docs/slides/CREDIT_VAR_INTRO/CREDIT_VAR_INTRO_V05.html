## *When one default becomes many*

> Credit VaR measures how assumptions about default dependence change the losses we must withstand.

# The Core Data Behind Credit VaR Credit VaR combines four inputs. The first two set the size of each loss; the last two set how often, and how *together*, those losses land. | Input | Question answered | Source | |---|---|---| | **Exposure (EAD)** | How much is at risk if a counterparty defaults? | CCR exposure engine | | **Loss severity (LGD)** | How much of that exposure is actually lost? | Obligor master | | **Counterparty credit quality (PD)** | How likely is each counterparty to default? | Obligor master (ratings / market / assumptions) | | **Default dependence** | How likely are defaults to occur together? | Factor universe & model calibration | > At the core, every model computes the same thing: *loss = EAD × LGD when a default occurs.* PD sets the frequency; dependence sets the tail.
